# release-check

**Goal:** Qualify software delivery separately from strategy/champion eligibility.

**Read:** `_BASELINE.md`, REL-01/PM-06, deployment profile, lock/migration/restore evidence, and risk register.

**Steps:** Verify core gates, security/resource/backup checks, rollback, no real-order capability, and pending forward-duration evidence. Do not equate software PASS with promotion.

**Output:** Release evidence matrix, command/exits, rollback result, pending G0–G7 gates, and activation prohibition when any gate is unmet.
