# next-sprint

## Goal

Select one genuinely eligible capability.

## Inputs and preconditions

Read manifest, execution waves, current claims and desired CORE/optional scope. Use root AGENTS and the exact relevant feature sprint; no phase-wide implementation scope.

## Procedure

1. Confirm request scope, ownership and current Git state.
2. Compute READY from DONE dependencies; check provider/data/host/portfolio gates; acquire bounded ownership.
3. Preserve failing evidence and all pre-existing WIP; record command exits rather than impressions.
4. Return selected ID, dependencies, worktree and required reading; if none eligible state exact blocker.

## Output and failure handling

Return selected ID, dependencies, worktree and required reading; if none eligible state exact blocker. If evidence is unavailable, state that explicitly and use BLOCKED/REVIEW as appropriate. Never bypass dependencies, silently expand scope or manufacture a reviewer identity. Product state changes remain owned by the coordinator.
