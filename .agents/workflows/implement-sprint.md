# implement-sprint

**Goal:** Deliver one sprint, or a batch of independent READY sprints, with focused evidence.

**Read:** `_BASELINE.md`, the chosen sprint, dependency handoffs, equivalent code, and existing tests.

**Steps:** Check dependencies/ownership once; implement each sprint's AC through public contracts; add focused regression tests (show RED when practical); run relevant checks; commit passing slices promptly; write concise handoffs for the exact SHA.

**Output:** Exact code SHA, changed scope, focused commands/results, material risks and status `REVIEW`.
