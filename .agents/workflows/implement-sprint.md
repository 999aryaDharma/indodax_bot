# implement-sprint

**Goal:** Deliver one independently reviewable capability.

**Read:** `_BASELINE.md`, the chosen sprint, dependency handoffs, equivalent code, and existing tests.

**Steps:** Claim one READY sprint; map every AC to a behavior test; prove RED then GREEN; integrate through public contracts; run required regression/lint; stage only allowed paths; commit and write the handoff.

**Output:** Exact branch/base/code/evidence SHA, AC matrix, commands/exits, risks/migration, deviations, and status `REVIEW`.
