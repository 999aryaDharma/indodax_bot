# implement-sprint

## Goal

Produce one reviewable capability.

## Inputs and preconditions

Read chosen sprint and dependency evidence, inspect equivalent modules and existing tests. Use root AGENTS and the exact relevant feature sprint; no phase-wide implementation scope.

## Procedure

1. Confirm request scope, ownership and current Git state.
2. For each AC prove targeted RED then GREEN; integrate through public boundary; verify scoped/full gates as required.
3. Preserve failing evidence and all pre-existing WIP; record command exits rather than impressions.
4. Commit scoped paths and create handoff; state REVIEW, not self-approved DONE.

## Output and failure handling

Commit scoped paths and create handoff; state REVIEW, not self-approved DONE. If evidence is unavailable, state that explicitly and use BLOCKED/REVIEW as appropriate. Never bypass dependencies, silently expand scope or manufacture a reviewer identity. Product state changes remain owned by the coordinator.
